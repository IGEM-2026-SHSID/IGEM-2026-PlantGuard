# 功能性规格（Functional Specification）

## 概述
功能性规格（Functional Specification）
Plant Guard-Multi”这个植物干旱多模块管理系统设计成 Hardware，核心思路是将三个功能模块（干旱报警、植物体内保水、土壤保水）整合成一个可部署在田间的物理设备系统，既能实时监测干旱，又能自动或半自动地响应干旱胁迫。


## 用例（Use Cases）
- 用例 1：干旱状态检测（完整）
  - 触发条件：颜色传感器监测凝珠变色程度达到设定阈值，且土壤湿度传感器读数低于干旱阈值（双重校验）
  - 步骤：封装于探针外壳内部的颜色传感器持续采集变色凝胶珠 RGB 色彩数据；探头开窗采用低反射率透明材料，降低环境光干扰。
主控同时读取土壤湿度传感器原始数据。
系统使用预训练模型比对色度值与土壤湿度，双重确认干旱事件，过滤单次环境光扰动造成的误触发。
干旱确认后，主控下发指令启动保水模块直流电机，挤破指定数量保水凝珠后停止电机。
主控通过 Wi‑Fi/LoRa 物联网模块向用户 App 推送紧急告警，上传当前凝胶 RGB 色度、土壤湿度、设备编号、时间戳。
用户收到告警后人工浇水，或设备外接自动浇水模块执行浇水。
水分渗入观测仓，变色凝胶珠遇水恢复原始色彩；传感器读到色彩复原，本轮抗旱流程结束，回到常态监测。
  - 验收条件：仅色度超限但湿度正常，系统不判定干旱，不触发保水与告警。
双重条件同时满足时，保水模块电机正常运转，挤破设定数量凝胶珠后自动停机。
App 可收到告警消息，消息附带完整色度、湿度、时间信息。
浇水后凝胶色彩复原，系统自动退出干旱状态，进入持续监测。
补充告警版本：干旱持续超过 3 天场景
  - 触发条件：干旱判定状态持续计时超过 72 小时
  - 步骤：颜色传感器蓝色通道 RGB 数值持续增强，同时土壤湿度维持在干旱区间，计时器累计时长。
计时到达 3 天阈值，推送更高优先级紧急通知：【Plant Guard】凝胶珠已变色，干旱持续超过3天，建议立即浇水。
  - 验收条件：干旱未到 3 天不触发该高优先级消息。
浇水恢复后计时器清零。

- 用例 2：保水模块
  - 触发条件：主控收到干旱确认信号（来自用例 1 双重校验通过）
  - 步骤：密封腔体内部直流电机通电，带动宽螺杆旋转；螺杆外部为多孔外壳，壳体内有序排列保水凝胶珠。
螺杆轴向推送凝胶珠向腔体前端移动，前端受机械挤压使凝胶珠破裂，释放内部保水因子渗透至周边土壤。
电机运行预设步数 / 时间后断电停止，避免过度消耗凝胶珠。
保水模块整体为长条模块化结构，通过线缆 + 标准接口和主控模块连接，支持拆卸更换。
  - 验收条件：未收到干旱信号，电机保持静止，凝胶珠无挤压破损。
触发信号到来，电机运转，可挤破设定数量凝胶珠后自动停止。
模块可插拔断开，不影响主控其他传感器正常工作。
多孔外壳可让释放出的保水因子向外扩散，凝胶珠碎片保留在腔体内部，不会漏入土壤。
功能清单与验收测试

## 功能清单与验收测试
- 功能 A：湿度监测
  - 输入：土壤湿度传感器模拟 / 数字原始信号
  - 输出：归一化土壤湿度百分比数值，时间戳；本地缓存 + 可选网络上报
  - 验收测试：
  探头置于干燥土壤：输出湿度处于干旱区间。
  探头置于充分润湿土壤：输出湿度处于正常区间。
  湿度读数随土壤含水量变化连续平滑，无跳变异常。
  传感器断线，主控识别故障状态并在 App 提示传感器异常。

  功能 B：干旱检测
  - 输入：凝胶珠 RGB 颜色读数、土壤湿度读数、干旱计时
  - 输出：干旱状态标记（正常 / 预警 / 确认干旱 / 长期干旱），触发事件信号给到保水模块与通信模块
  - 验收测试：
通过模型比对色度值与土壤湿度，双重校验，单一条件超限不触发干旱确认。
干旱确认输出事件信号，驱动保水模块电机挤破若干保水凝珠后停止。
主控将变色凝珠色度值、湿度、时间通过网络上传。
浇水后凝胶色彩恢复，系统自动重置干旱标记，完成一轮抗干旱流程。

功能 C：保水触发
  - 输入：主控输出 “干旱确认” 逻辑信号
  - 输出：电机驱动脉冲，螺杆旋转，定量挤破保水凝胶珠；运行完成状态反馈给主控
  - 验收测试：
  正常状态下电机不动作，凝胶珠完好。
收到触发信号，电机运转，挤破预设数量凝胶珠后自动停机。
连续多次触发，消耗后续凝胶珠；凝胶珠耗尽后上报 “耗材用尽” 状态。
机械卡滞时，电机超时保护停机，上报故障，不烧毁驱动硬件。

功能 D：App 报警
  - 输入：干旱确认事件、长期干旱超时事件、传感器故障、耗材耗尽事件
  - 输出：手机 App 弹窗 / 推送通知，附带设备 ID、RGB 色度、土壤湿度、时间戳、告警等级
  - 验收测试：
  普通干旱触发：收到标准干旱告警。
干旱持续 > 3 天：收到高优先级提示【Plant Guard】凝胶珠已变色，干旱持续超过3天，建议立即浇水。
传感器断开、凝胶耗材耗尽，App 收到对应故障提醒。
网络短暂离线，恢复联网后补发缓存告警，不丢失关键事件。

功能 E：便携模块化
  - 输入：人为插拔探头模块、保水模块线缆接口
  - 输出：模块热插拔识别；已接入模块正常工作；未接入模块标记缺失，不阻塞其余功能
  - 验收测试：
  颜色‑湿度探针、保水模块可通过 Type‑C 类接口快速拆装移位。
拔掉保水模块，检测模块仍然继续监测上报，App 提示 “保水模块未连接”。
更换新探头后系统自动读取传感器，无需重新烧录固件。

功能 F：防水
  - 输入：外部水汽、土壤泥水、浇灌淋水
  - 输出：电子主控腔室内无进水，探头与保水模块耐受田间潮湿环境；发生进水风险标记故障
  - 验收测试：
  探头、保水模块外壳可耐受浇灌淋水、埋入潮湿土壤，无渗水进入电子元器件仓。
主控电路板密封仓不允许长期浸水。
模拟进水条件，设备触发故障上报，不发生短路。

功能 G：通信（物联网）
  - 输入：设备内部事件、传感器数据；云端 / App 下发的配置指令（告警阈值、电机运行时长）
  - 输出：上行：传感器数据、告警、设备状态；下行：阈值参数配置；离线本地缓存事件
  - 验收测试：
  Wi‑Fi/LoRa 正常连接：告警与传感数据成功上传 App。
断开网络：事件在本地缓存；网络恢复后完成补发。
App 下发修改干旱阈值，设备读取并应用新参数。
低功耗休眠模式下，维持周期性上报，不会耗尽电池。


## 性能目标
- 干旱判定响应时间：色彩 + 湿度双重校验完成≤10 s；从条件满足到发出告警≤15 s。
- 颜色传感器精度：RGB 通道采样分辨率 8‑bit；环境光变化 ±15% 条件下，凝胶变色识别准确率≥90%。
- 土壤湿度测量：测量范围 0‑100% 体积含水量；相对误差≤±5%。
- 保水模块执行：单次触发挤破凝胶珠数量误差 ±1 颗；电机从启动到停机完成≤3 s。
- 告警延迟：网络正常情况下 App 推送到达延迟≤15min。
- 续航：太阳能 + 锂电池供电，常态监测模式，无阳光环境下至少连续运行 7 天。
- 误触发率：单一环境光扰动、瞬时湿度波动导致的假干旱触发＜5%。


## 依赖项
- 土壤湿度探头
- 变色凝胶珠透明低反射观测仓
- RGB 颜色传感器模块
- 直流减速电机 + 螺杆‑多孔外壳机械结构（微流控缓释装置）
- 滴灌外部对接接口（接第三方自动浇水）
- Wi‑Fi / LoRa 低功耗物联网通信模块
- 主控单片机
- 太阳能光伏板、可充电锂电池、电源管理单元
- Type‑C 规格模块化线缆接口
- 单片机底层外设驱动（ADC 读取传感器、PWM 电机驱动）
- 色度‑湿度干旱判别模型（本地运行轻量推理）
- 物联网通信库（MQTT 协议）
- 手机端 App（接收推送、展示传感数据、配置阈值）
- 时间计时库，用于干旱持续时长统计
- 外部服务
- MQTT 消息中转服务，实现设备‑App 消息传递
