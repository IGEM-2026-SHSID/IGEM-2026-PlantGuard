# 装配与用户手册（User Manual & Calibration）

## 快速开始
### 1.开箱检查
确认一个 PlantGuard hardware unit 的主要组件完整：
* ESP32-CAM
* DHT30 温湿度传感器
* MQ 系列传感器（如使用）
* LED/补光模块
* 电源及连接线
* 固定支架和约 20 × 30 cm 底板
使用前检查元件、线路和接口是否存在明显损坏或松动。
### 2.硬件连接
按照接线图将传感器、ESP32-CAM 和其他模块连接。连接完成后固定线路，避免实验过程中因移动造成接触不良。
电子元件应与植物浇水区域保持适当距离，避免水直接接触电路。
### 3.电源要求
* 建议采用稳定的 **5 V DC** 低压电源。
* 单个 unit 正常运行功耗预计约 **1–2 W**。
* 通电前确认正负极和各模块接线正确。
* 调整线路或更换组件前应先断开电源。
### 4.界面说明
接通电源并启动系统后：
1. 确认 ESP32-CAM 正常运行。
2. 检查 DHT30 等传感器是否持续返回数据。
3. 检查摄像头能否正常获取植物图像。
4. 确认图像清晰、植物处于预设拍摄区域内。
5. 确认数据能够正常保存或传输。

## 装配步骤
1. **安装底板与支架**
   将支架固定于约 20 × 30 cm 的设备底板上，确保整体结构稳定。
2. **安装 ESP32-CAM**
   将摄像头固定在预定位置，并调整角度，使目标植物位于主要拍摄区域内。
3. **安装环境传感器**
   将 DHT30 等传感器安装于指定位置。不同 hardware unit 应尽可能保持相同的安装高度和位置。
4. **安装补光模块**
   如使用 LED 补光，将光源固定于预定位置，避免不同实验之间出现明显的光照差异。
5. **连接线路**
   根据接线图连接 ESP32-CAM、传感器及电源模块，并检查各接口是否牢固。
6. **整理和固定线路**
   使用固定装置整理线路，避免裸露、松动或与水直接接触。
7. **通电测试**
   接通电源，分别测试摄像头、温湿度传感器及其他模块是否正常工作。
8. **放置植物并调整位置**
   将植物置于预定监测位置，确保摄像头视野、传感器位置及光照条件符合实验要求。

## 校准说明
### 1. 温湿度传感器校准
1. 将 DHT30 与可靠的参考温湿度计放置在相同环境中。
2. 等待读数稳定。
3. 同时记录 PlantGuard 与参考仪器的温度和湿度数据。
4. 重复测量至少 **3次**。
5. 计算两者之间的偏差；如存在稳定的系统性偏差，在数据处理中进行校正并记录校正参数。

**示例：**
参考湿度 = 50% RH
传感器读数 = 52% RH
偏差 = +2% RH

则应记录该偏差，并在后续测量中使用统一的校正方法。

### 2. ESP32-CAM 校准
1. 将摄像头固定于最终使用位置。
2. 放置标准测试植物或参考目标。
3. 调整摄像头角度和距离，使目标完整进入画面。
4. 固定图像分辨率及相关拍摄参数。
5. 在正常光照条件下获取参考图像。
6. 如采用 HSV 等图像分析方法，根据参考图像确定初始阈值。
7. 在后续测试中保持摄像头位置、背景和光照条件尽可能一致。

### 3. 系统检测阈值校准
分别采集正常供水和不同程度干旱条件下的传感器及图像数据，根据实验结果确定 drought detection threshold。
在获得足够验证数据后，再确定最终的灵敏度和误报率。**90% sensitivity 和 <10% false-positive rate 应作为目标性能，而不是未经实验验证的实际性能。**

## 常见故障排查
| 问题 | 可能原因 | 解决方法 |
| ESP32-CAM 无法启动 | 供电不足或接线错误 | 检查 5 V 电源及线路连接 |
| 摄像头无图像 | 摄像头连接或固件异常 | 重启设备并检查摄像头及固件配置 |
| 图像过暗/过亮 | 环境光变化或补光位置不合适 | 调整并固定补光位置 |
| DHT30 无数据 | 接线松动或引脚配置错误 | 检查线路和固件中的引脚设置 |
| 传感器读数异常 ｜ 环境干扰或未校准 | 与参考仪器比较并重新校准 |
| 干旱识别结果不稳定 | 光照、拍摄位置或阈值变化 | 固定实验条件并重新检查识别阈值 |
| 数据传输中断 | 电源、线路或通信异常 | 检查供电和连接，必要时重启系统 
| 设备接触水后异常 | 水进入电子元件 | 立即断电，停止使用并检查设备，确认安全后再重新启动 |

**安全提示：** 设备运行期间应避免电子元件直接接触水。任何线路调整、维修或组件更换均应在断电状态下进行。
