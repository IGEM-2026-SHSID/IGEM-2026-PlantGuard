# 传感器候选与选择（Sensor Selection）

## 目标测量量与要求
- 测量量：
  - 土壤体积含水量（VWC）
  - 环境温度与相对湿度
  - 光照强度
  - 空气质量/挥发性有机物（可选）
  - 凝胶凝珠颜色强度/蓝色通道变化（干旱指示）
- 量程：
  - 土壤湿度：0–100%（体积含水量或电容值对应）
  - 温度：-40–80°C
  - 相对湿度：0–100% RH
  - 光照：0–65535 lux（常用模块范围）
  - RGB/色度：0–255（单通道）或归一化颜色指数
  - 空气质量：0–1000 ppm VOC / 0–10,000 ppm CO2 等级（视模块而定）
- 所需精度/分辨率：
  - 土壤湿度：±2%~±5%（适合田间粗判）
  - 温度：±0.3°C~±1°C
  - 相对湿度：±2% RH~±5% RH
  - 光照：1 lux 级分辨率
  - 颜色：8-bit RGB 分辨率，足以识别凝珠蓝色强度变化
  - 采样周期：1–5 min，适合低功耗田间部署

## 评估要点
- 成本：优先选用低成本、模块化、可替代性强的元件，便于田间批量部署。
- 可得性：应优先考虑国内供应链稳定、可快速采购的模块，避免交期风险。
- 精度：土壤湿度与凝珠色度是核心判定指标，温湿度和光照是修正变量，任何测量误差都可能影响干旱阈值。
- 接口兼容性：传感器需兼容 ESP32-S3 / ESP32-CAM 等主控平台，优先选择 I2C、ADC、UART 易接入方案。
- 封装/防护等级：田间环境潮湿、多尘，建议采用防潮、防腐、耐候封装；土壤侧传感器需避免直接暴露在液体中。
- 量产能力：选择模块通用、代码成熟、替代型号多的器件，便于后续试验迭代和批量生产。

## 推荐与替代方案
- 推荐：
  - 土壤湿度：Capacitive Soil Moisture Sensor V1.2（主传感器）
  - 温湿度：DHT30（基础环境监测）
  - 光照：BH1750（补偿环境光）
  - 凝珠色度：TCS34725 或 ESP32-CAM 图像识别（主/辅方案）
  - 空气质量：MQ-135（可选辅助变量，非决定因素）
  - 控制主机：ESP32-S3，负责汇总数据并做干旱判定
- 备选：
  - 若需要更高精度，可将 DHT30 替换为 SHT31。
  - 若对色度识别更敏感，可用 TCS34725 替代单纯摄像头数值判断，降低环境光影响。
  - 若需要更强图像分析能力，可采用 ESP32-CAM + OpenCV/HSV 阈值法，对凝胶凝珠颜色做二次确认。
  - 若要减少校准复杂度，可用 CCS811 替代 MQ-135，改善空气质量数据稳定性。

> 结论：本系统的核心传感器组合应以“土壤湿度 + 凝珠色度 + 温湿度/光照修正”为主，采用 ESP32-S3 作为主控，确保在低成本、低功耗和田间可维护性之间取得平衡。
