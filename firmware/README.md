# 固件（Firmware）说明

包含固件源码、构建脚本、烧录说明与测试用例。
- [Micropython库](https://pypi.org/project/micropython-esp32-stubs/) 开发用
- [配置你的开发板](https://github.com/ainovicezh/ESP32C3mini-OLED-MicroPython) 配置示例

建议内容：
- `src/` - 源代码
- `platformio.ini` 或 `Makefile` - 构建说明
- `docs/` - 固件 API 与通信协议说明
- `flash_instructions.md` - 烧录与调试指南
